# StudyPlanController Project Plan

## 1. Project Purpose

StudyPlanController is a web-based system that helps university students organise subjects, study tasks and deadlines.

## 2. Target Users

The target users are university students who need a simple system to manage their study plans.

## 3. Core Features

### Subject Management

- Add a subject
- View subjects
- Edit a subject
- Delete a subject

### Study Task Management

- Add a study task
- Select the related subject
- Add a task description
- Set a due date
- Select a priority
- Edit a task
- Delete a task
- Mark a task as completed

### Dashboard

- Display the total number of tasks
- Display completed tasks
- Display pending tasks
- Display overdue tasks
- Display upcoming deadlines

### Task Filtering

- Filter tasks by subject
- Filter tasks by status
- Filter tasks by priority
- Filter tasks by due date

## 4. Main Pages

- Home page
- Dashboard
- Subject management page
- Add subject page
- Task management page
- Add task page
- Edit task page

## 5. Technologies

- Python
- Flask
- HTML
- CSS
- Bootstrap
- SQLite
- Git
- GitHub

## 6. Features Outside the Current Scope

The first version will not include:

- Artificial intelligence
- Email notifications
- Group collaboration
- Mobile application
- Online payment

## 7. Success Criteria

The project will be successful when users can:

- Manage subjects
- Create and update study tasks
- Track task deadlines
- Mark tasks as completed
- View accurate information on the dashboard
