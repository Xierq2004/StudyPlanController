# StudyPlanController Project Plan

## 1. Project Purpose

StudyPlanController is a web-based study plan management system for university students. The system will help students organise subjects, create study tasks, track deadlines and monitor their study progress.

## 2. Target Users

The target users are university students who need a simple way to manage their subjects, assessments and study deadlines.

## 3. Core Features

### Subject Management

Users will be able to:

- Add a subject
- View all subjects
- Edit a subject
- Delete a subject

### Study Task Management

Users will be able to:

- Create a study task
- Select the related subject
- Add a task description
- Set a due date
- Select a priority
- Edit a task
- Delete a task
- Mark a task as completed

### Dashboard

The dashboard will display:

- Total number of tasks
- Number of completed tasks
- Number of pending tasks
- Number of overdue tasks
- Upcoming deadlines

### Task Filtering

Users will be able to filter tasks by:

- Subject
- Completion status
- Priority
- Due date

## 4. Main Pages

The application will contain:

- Home page
- Dashboard
- Subject list page
- Add subject page
- Task list page
- Add task page
- Edit task page

## 5. Technologies

The project will use:

- Python
- Flask
- HTML
- CSS
- Bootstrap
- SQLite
- Git
- GitHub

## 6. Features Outside the Current Scope

The first version will not include:

- Artificial intelligence
- Mobile application
- Email notifications
- Group collaboration
- Online payment
- Social media integration

These features may be considered in a future version.

## 7. Success Criteria

The project will be considered successful when:

- Users can manage subjects
- Users can manage study tasks
- Users can track deadlines
- Users can update task status
- The dashboard displays accurate task information
- The application runs without major errors
